# ScholarPath

ScholarPath is an interactive study-plan map for the Information Engineering program at Qasioun University. It presents courses, credit hours, course categories, and prerequisites as a navigable graph so students can understand the structure of their degree.

## Features

- Interactive curriculum graph powered by React Flow
- Course cards with course codes, Arabic titles, credit hours, and requirement categories
- Visual prerequisite relationships between courses
- Pan, zoom, and fit-to-view controls
- Arabic curriculum content for the current study plan
- GitHub Pages deployment support
